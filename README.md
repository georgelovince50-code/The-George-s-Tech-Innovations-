## Website status
This repository now contains a static Astro marketing website for The George's Tech Innovations, including reusable sections, blog content collections, and a newsletter signup form.

## Deployment
This project is configured to deploy to Netlify through GitHub Actions.

### Required GitHub secrets
- NETLIFY_AUTH_TOKEN
- NETLIFY_SITE_ID

Push to the main branch or run the workflow manually to trigger a deployment.

## Local development
- `npm install`
- `npm run dev`
- `npm run build`
